# X Native Extension 1.1.1

Install by unzipping `x-native-extension-unpacked.zip` and loading that folder with **Load unpacked**. The folder must contain `manifest.json`. See `INSTALL.md`. Check `SHA256SUMS.txt` against the downloaded files before loading them.

`x-native-extension-source.zip` is the source, tests, and docs. It is not the folder Chrome loads.

## This version

- A photo’s menu is Download full image from post, Open image in new tab, Post image, and Screenshot post.
- A video, poster, or play control’s menu is the video versions of those actions, plus Screenshot post.
- A text post’s menu is Screenshot post only.
- Open image opens the full-size image, not the post. Open video opens a progressive MP4 or WebM the page already named.
- Post image and Post video attach that file on a composer for review. They never click Post.

## Known limits

- Attaching a file on a signed-in x.com composer was not verified. The fixture records the file on the input and that Post was not clicked. The `change` event is untrusted, so the live composer can ignore it and show an empty preview.
- Brave was not tested.
- Screenshot from the on-page menu needs a prior extension invocation. Use Alt+Shift+S, or Alt+right-click and choose Screenshot post in the browser menu.
- Blob addresses and segmented streams are not opened and are not attached. No media URL is invented.
- Files over 32 MB are refused. At most four images are attached.
- No license is granted yet.
