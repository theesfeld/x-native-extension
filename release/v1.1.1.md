# X Native Extension 1.1.1

Install from **x-native-extension-unpacked.zip** on this release. Unzip it and load the folder that contains `manifest.json` with **Load unpacked**. Check `SHA256SUMS.txt` before you load it.

**Source code (zip)** and **Source code (tar.gz)** are GitHub’s snapshot of the repository. They are not the extension. `x-native-extension-source.zip` is that same kind of snapshot, for reading the project.

## This version

- A photo’s menu is Download full image from post, Open image in new tab, Post image, and Screenshot post.
- A video, its poster, or the play control offers the video versions of those actions, plus Screenshot post.
- A text post offers Screenshot post only.
- Open image opens the full-size image. Open video opens a progressive MP4 or WebM the page already named. A blob address or a segmented stream is refused.
- Post image and Post video attach the file for review. They do not click Post. An existing draft is left alone and a new composer tab is used.

## Limits

- A signed-in x.com composer was not checked. The fixture recorded the file on the picker and that Post was not clicked. X can ignore the attachment notice, so the preview can stay empty.
- Brave was not tested.
- Screenshot from the on-page menu needs Alt+Shift+S, or Screenshot post in the browser menu after Alt+right-click.
- Files over 32 MB are refused. At most four images are attached.
- No license is granted.

Upgrade: replace the loaded folder, click Reload on the extension, and refresh open x.com tabs. Details are in the project README.
